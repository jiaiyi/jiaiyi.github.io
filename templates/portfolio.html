三个从零写完、能跑起来的项目，每个都附了架构说明和我踩过的坑。 技术栈集中在一条线上：文档进知识库 → 检索 → 交给 Agent 编排 → 输出结论。

项目一 · RAG 系统 LangGraphMilvusFastAPI

教育知识库 · 智能问答 RAG

把 Word / PDF / Markdown 讲义和题库导入知识库，支持课程检索、课程详情、文档问答、 题库检索、闲聊五类对话，单端口同时提供 4 个 Web 页面。

约 1 万行 Python。导入与查询拆成两张 LangGraph 图（9 节点 / 10 节点）； 检索走 BGE-M3 稠密+稀疏混合检索 → RRF 融合 → BGE-Reranker 重排； 存储用 Milvus + MongoDB + MinIO。

代码 拆图设计 单端口合并踩坑 检索路由

项目二 · 多智能体 deepagentsFastAPIWebSocket

Deep Search · 深度检索服务

把联网搜索、MySQL 查询、企业知识库三条检索链路分给三个子 Agent， 主 Agent 只负责拆解与汇总，最后产出一份带出处的 Markdown 报告并转 PDF。

按信息源拆子 Agent，避免一个 Agent 挂几十个工具导致选错工具； 每个会话独立目录隔离上传与产物；执行过程通过 WebSocket 实时推给前端。

Deep Agent · 能力清单与旅行规划助手

20 个可单独运行的最小示例，覆盖流式输出、子智能体（含嵌套）、人工审批（含改参数）、 存储后端、权限（全局只读 / 目录隔离）、技能与上下文。
